# Frost Music Lab

Frost Music Lab is a Next.js training app for Theory IV, Aural Skills IV, and Class Piano IV proficiency drills.

## Run locally

```bash
npm ci
npm run dev
```

## Quality checks

```bash
npm run lint
npm test
npm run build
```

## Test coverage focus

- Twelve-tone matrix/transformation correctness
- Flat-key and flat-chord spelling
- Audio pitch-detection stability checks
- Adaptive mastery and streak persistence behavior
